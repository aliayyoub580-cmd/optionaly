# Optionaly — Real-Time Binary Options Trading Platform

Optionaly is a full-stack high-performance trading platform built with Express, React (Vite), Lightweight Charts, and Supabase (PostgreSQL).

## Features
- **Real-Time Trading Engine**: 5s, 15s, 30s, 1m, 2m, 3m, 5m trading timeframes with continuous market simulation.
- **Supabase / PostgreSQL Database**: Fully migrated and integrated with all 25 tables.
- **Interactive Charts**: Lightweight Charts with live trades, countdown timers, and win/loss animations.
- **Admin Dashboard**: Full platform control, risk management, and user management.
- **Multi-Asset Support**: Crypto, Forex, and Commodities.

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
